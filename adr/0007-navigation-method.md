# 7. Navigation Method

Date: 2026-06-13

## Status

Accepted

## Context

The app we are designing needs a navigation method when transitioning between pages.

## Decision

We plan to implement a mix of stack and tab navigation to allow for a navigation bar as well as buttons to open specific features/pages.

## Consequences

This will make it possible to navigate within the app while introducing some difficulties to properly implent a mix of the two navigation types. This will also introduce the option to include a visual cue for when pages are being switched.

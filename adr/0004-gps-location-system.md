# 4. GPS Location System

Date: 2026-06-13

## Status

Accepted

## Context

When registering for an event you have planned to come up, the reminder may show on your phone, but the location of the event may still slip your mind. Allowing easy viewing of the exact location rather than just the name, it leaves no room for confusion. 

## Decision

Allowing a sample screenshot of the location to be selected. Showing roads and so on with a pop-up pin showing the exact location of the inputted event. There will be a text bar for input, prompting an optional address search, with the screenshot being of the location being used upon inputting the address. This will also include an option to copy the address to post in a navigation app and get directions.

## Consequences

With this feature implemented It will be easier to view distance and time to events and plan your trip accordingly, provide a reminder of where the event is taking place, as well as distinction between similarly named events. 

This feature will also bring up some difficulties including the possibility of a cluttered look because of too much information on one event, and could provide difficulties for some users if more then one event takes place at the same address. This will also provide challenges for implementaion for figuring out how to implement location based software.

# 7. Calendar View

Date: 2026-06-13

## Status

Accepted

## Context

The top half portion of the app defaults to a large calendar view for split screen for easy navigation.

## Decision

We plan to implement a mix of stack navigations to allow for split screen to work smoothly.

## Consequences

This will make it possible to quickly see through different events in different events. For users who don't like it, there will be an option in settings to turn it into a tab mode.
